# Prestofatto Bra

Sito statico per Prestofatto, pizzeria al taglio e gastronomia veloce in via Don Luigi Orione 45 a Bra.

## File principali

- `index.html`: pagina one-page con hero, menu, specialità, orari, posizione e contatti.
- `styles.css`: identita visuale derivata dal logo, layout responsive e stati del menu.
- `script.js`: menu mobile, stato header, tab del menu e ticker delle proposte.
- `404.html`: pagina di errore coerente con lo stile del sito.
- `manifest.json`, `robots.txt`, `sitemap.xml`: supporto base per browser, crawler e SEO.
- `assets/`: immagini locali usate nel sito.

## Note progetto

Il sito usa solo HTML, CSS e JavaScript statici. Non richiede build, CDN o dipendenze esterne obbligatorie.

La palette riprende il logo Prestofatto: rosso aranciato, giallo caldo, nero marcato e superfici chiare. Le immagini sono quelle reali disponibili per il progetto; non sono stati aggiunti placeholder.

Prima della pubblicazione definitiva, sostituire il dominio dimostrativo in `robots.txt` e `sitemap.xml` con l'URL reale di produzione.

## Apertura locale

Aprire `index.html` direttamente nel browser oppure servire la cartella con un server statico.
